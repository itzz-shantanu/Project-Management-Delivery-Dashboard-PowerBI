# 📊 Project Management & Delivery Dashboard

An interactive Power BI dashboard designed to provide an overview of project portfolios, monitor project timelines, and explore individual project-level details. The report brings together portfolio KPIs, regional and departmental distribution, project status, delivery phases, and a Gantt-style project timeline to support project monitoring and analysis.

## 📊 Dashboards Overview

The report is organized into three interactive pages:

### 1. Project Management Summary

This page provides a high-level view of the project portfolio and its overall distribution.

<img width="1467" height="822" alt="Project Management   Delivery Dashboard-1" src="https://github.com/user-attachments/assets/47ed5edc-7bf9-4b7a-af6e-a995b2b9435e" />


**Key elements:**
- **Portfolio KPIs:** Total Projects, Project Cost, Benefits, and Benefit Cost Ratio.
- **Project Trends:** Monthly trend of projects across the year.
- **Regional Distribution:** Project distribution across East, West, North, and South.
- **Project Status:** Distribution across Completed, Cancelled, On-Hold, and In-Progress projects.
- **Benefits – Cost Ratio:** Comparison of benefit-cost ratio across projects.
- **Department Analysis:** Project distribution across departments such as eCommerce, Admin & BI, Warehouse, Sales and Marketing, and Supply Chain.
- **Phase Progress:** Progress across the five project phases — Explore, Develop, Plan, Implement, and Measure.

### 2. Project Timeline

This page focuses on the time dimension of project delivery and phase-wise progress.

<img width="1462" height="822" alt="Project Management   Delivery Dashboard-2" src="https://github.com/user-attachments/assets/8658f3e7-7e4c-4180-bbd0-3221fd4c5068" />

**Key elements:**
- Monthly trend of projects.
- Gantt-style project timeline showing project schedules over time.
- Phase-based timeline legend covering Explore, Develop, Plan, Implement, and Measure.
- Project-level timeline rows to compare schedules and progress.
- Project Name and Year slicers to narrow the displayed timeline.

### 3. Project Details

This page provides a detailed, tabular view of individual projects and their key attributes.

<img width="1467" height="822" alt="Project Management   Delivery Dashboard-3" src="https://github.com/user-attachments/assets/3fe29a85-0945-48f2-91ea-27429fbb4b33" />

**Key elements:**
- Project Name and Project Type.
- Region and Project Manager.
- Project Complexity.
- Start Date and End Date.
- Project Cost and Project Benefit.
- Completion Percentage and Status.
- Slicers for Region, Project Type, Project Name, Project Manager, and Year.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — report development and interactive data visualization.
- **Power BI visuals** — KPI cards, line and donut charts, bar charts, phase progress visualization, and Gantt-style timeline.

## 🔑 Key Insights from the Dashboard

- The summary page presents the portfolio at a glance, including total projects, overall project cost, benefits, and benefit-cost ratio.
- Regional and status distributions make it easier to compare how projects are spread across locations and delivery states.
- Department-level analysis highlights where projects are distributed across business functions.
- Phase progress and the Gantt-style timeline provide complementary views of project delivery: one summarizes phase completion, while the other shows project schedules over time.
- The project details page supports closer examination of individual project cost, benefits, ownership, complexity, dates, completion, and status.

## 🚀 How to Use

1. Download the `.pbix` file from the `Dashboard` folder.
2. Open it using Microsoft Power BI Desktop.
3. Use the slicers and report visuals to explore the project portfolio, timelines, phases, and project-level details.
